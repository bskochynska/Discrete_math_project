Звіт командного проєкту
Тема проєкту: Задача комівояжера та оптимальна доставка вантажів
Проєкт реалізує два підходи до знаходження оптимальних маршрутів у транспортній
мережі:
● Точний алгоритм (перебір з оптимізаціями)
● Жадібний алгоритм
Додатково створена анімаційна візуалізація руху вантажівок, а також система
зчитування даних з CSV-файлів та модуль для порівняння швидкодії та точності двох алгоритмів.
Алгоритми, використані в проєкті:
1. Дискретна математика та модель графа
Усі дані моделюються у вигляді неорієнтованого зваженого графа:
● вершини — міста
● ребра — дороги
● ваги — відстані
Ми працювали з такими поняттями дискретної математики:
- множини (вершини, маршрути, набори посилок)
- відображення (місто → сусіди → відстані)
- графи
- комбінації та перестановки (точний алгоритм)
- жадібний алгоритм
- алгоритм Дейкстри
3. Точний алгоритм
Точний метод перебирає усі можливі перестановки міст, щоб знайти мінімальний шлях,
який проходить через усі призначення та повертається до складу.
Основні компоненти:
● Генерація всіх перестановок міст
● Розрахунок довжини кожного маршруту
● Повернення абсолютно оптимального результату
● Використання “принципу гілок і меж” для обрізання довгих шляхів
Цей метод гарантує найкоротший маршрут, але є повільним для великих графів, тому ми
фільтруємо в коді для якої кількості який з них використовувати, для <= 10 буде
використовуватись точний, інакше - жадібний
4. Жадібний алгоритм
Підхід, який працює значно швидше:
1. Починаємо зі складу
2. На кожному кроці обираємо найближче ще не відвідане місто
3. Повторюємо, поки всі пункти доставки не відвідані
4. Повертаємося до складу
Переваги:
● Швидкість
● Простота
● Хороший результат на середніх графахНедоліки:
● Результат не завжди оптимальний, але наближений.
4. Алгоритм Дейкстри для пошуку найкоротших
шляхів (використовується в обох алгоритмах)
Ми застосовуємо Дейкстри для:
● знаходження найкоротших шляхів між окремими містами
● формування реального маршруту вантажівки склад → призначення
Основні принципи:
● пріоритетна черга (мінімальне ребро першим)
● гарантія найкоротшого шляху у графі без негативних ваг
Візуалізація
У файлі visualisation.py реалізовано:
Побудову графа
● міста як вершини
● дороги як ребра
● склад — жовтий вузолВиділення оптимальних маршрутів
● різні вантажівки — різні кольори
● підсвічені лінії шляху
Анімацію руху "машинок"
● кожен маршрут розбивається на багато проміжних точок
● вантажівка рухається плавно
● залишає "хвіст" шляху
● біля неї відображається ID
Робота з CSV
У файлі data_input.py реалізовано:
● зчитування графа graph.csv
● імпорт вантажівок vehicles.csv
● імпорт посилок packages.csv
● перетворення даних у структури Python
Процес виконання проєкту:
Умовно наша робота поділялася на етапи:
1. Аналіз класичної задачі комівояжера
2. Побудова графа та структури проєкту
3. Написання data_input.py та зчитування CSV-файлів4. Реалізація точного алгоритму
5. Реалізація жадібного алгоритму
6. Реалізація допоміжних алгоритмів (Дейкстра, пошук шляхів)
7. Побудова візуалізації та анімації
8. Порівняльний аналіз алгоритмів
9. Підготовка фінальної презентації та звіту
